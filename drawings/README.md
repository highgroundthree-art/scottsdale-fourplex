# Drawings
Concept designs for the three building models (Model 1, Model 2, Model 3). Each drawing is listed in `data/sheets.json`.

| Folder | Contents |
|---|---|
| `elevations/` | Street elevations |
| `site-plans/` | Site plans, one per model |
| `floor-plans/` | Floor plans, every level of every model |

Concept design, not for construction.
